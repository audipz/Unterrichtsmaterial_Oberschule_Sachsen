Glossar

Dieses Glossar erklärt wichtige Begriffe aus dem Informatikunterricht.

Die Begriffe sind nach Themen geordnet.

Jeder Begriff besteht aus

  • einer kurzen Definition,
  • einem Beispiel,
  • einem Hinweis auf verwandte Begriffe.

Das Glossar wird mit jedem Kapitel erweitert.

Algorithmen

Algorithmus

Ein Algorithmus ist eine eindeutige und ausführbare Folge von Handlungsschritten zur Lösung eines Problems.

Beispiel

Rezept zum Backen eines Kuchens

Programm zur Berechnung einer Summe

Siehe auch

  • Programm
  • Sequenz
  • Verzweigung
  • Wiederholung

Sequenz

Eine Sequenz ist eine Folge von Handlungsschritten.

Sie werden nacheinander ausgeführt.

Beispiel

Tasse nehmen

Milch eingießen

Kakao einfüllen

Umrühren

Verzweigung

Eine Verzweigung entscheidet,

welcher Weg ausgeführt wird.

Beispiel

Wenn es regnet,

dann Schirm benutzen,

sonst ohne Schirm gehen.

Wiederholung

Eine Wiederholung führt dieselben Schritte mehrfach aus.

Beispiel

10-mal springen

Bedingung

Eine Bedingung entscheidet,

ob eine Handlung ausgeführt wird.

Beispiel

Ist die Ampel grün?

Programm

Ein Programm beschreibt einen Algorithmus in einer Programmiersprache.

Beispiel

Python

Scratch

Java

C#

Daten

Daten

Daten sind Informationen,

die gespeichert oder verarbeitet werden können.

Beispiele

  • Zahlen
  • Texte
  • Bilder
  • Musik

Information

Information entsteht,

wenn Daten eine Bedeutung erhalten.

Eingabe

Daten,

die ein Programm erhält.

Ausgabe

Daten,

die ein Programm ausgibt.

Verarbeitung

Schritte,

mit denen Daten verändert werden.

Programmierung

Programmiersprache

Eine Programmiersprache dient dazu,

Algorithmen zu beschreiben.

Beispiele

  • Scratch
  • Python
  • Java
  • C#
  • VBA

Syntax

Die Syntax beschreibt die Schreibregeln einer Programmiersprache.

Quellcode

Der Quellcode ist der Text,

den Programmierer schreiben.

Debugging

Debugging bedeutet,

Fehler systematisch zu suchen und zu beheben.

Compiler

Ein Compiler übersetzt Quellcode in ein ausführbares Programm.

Interpreter

Ein Interpreter führt Programme direkt aus.

Python verwendet üblicherweise einen Interpreter.

Künstliche Intelligenz

KI

Künstliche Intelligenz bezeichnet Computersysteme,

die Aufgaben lösen,

für die normalerweise menschliche Intelligenz erforderlich ist. :contentReferenceoaicite:0

Prompt

Ein Prompt ist eine Eingabe,

mit der eine KI gesteuert wird.

Halluzination

Eine Halluzination ist eine falsche,

aber überzeugend klingende Antwort einer KI.

Sprachmodell

Ein Sprachmodell berechnet,

welche Wörter wahrscheinlich aufeinander folgen. :contentReferenceoaicite:1

Token

Token sind kleine Einheiten,

in die ein Text zerlegt wird,

damit ein Sprachmodell ihn verarbeiten kann. :contentReferenceoaicite:2

Internet

Internet

Das Internet verbindet weltweit Millionen von Computern.

World Wide Web

Das World Wide Web (WWW)

ist ein Dienst des Internets.

Webseiten werden über Browser angezeigt.

Browser

Ein Browser zeigt Webseiten an.

Beispiele

  • Firefox
  • Chrome
  • Edge
  • Safari

URL

Eine URL ist die Adresse einer Webseite.

Download

Beim Download werden Dateien aus dem Internet auf den eigenen Computer übertragen.

Upload

Beim Upload werden Dateien vom eigenen Computer ins Internet übertragen.

Open Source und OER

Open Source

Open Source bedeutet,

dass der Quellcode öffentlich verfügbar ist.

Andere Personen können ihn lesen,

verbessern und weiterentwickeln.

OER

Open Educational Resources

sind frei nutzbare Bildungsmaterialien.

Repository

Ein Repository ist ein Projektordner,

der Dateien und ihre Versionsgeschichte enthält.

Commit

Ein Commit speichert Änderungen.

Lizenz

Eine Lizenz beschreibt,

unter welchen Bedingungen Materialien genutzt werden dürfen.

Creative Commons

Creative-Commons-Lizenzen ermöglichen,

Materialien unter bestimmten Bedingungen weiterzugeben und zu verändern.
