Was ist GitHub?

GitHub ist eine Internetplattform.

Dort können Projekte gemeinsam entwickelt werden.

Viele Programme und Unterrichtsmaterialien entstehen heute auf GitHub.

Warum GitHub?

GitHub

  • speichert alle Versionen,
  • ermöglicht Zusammenarbeit,
  • dokumentiert Änderungen,
  • erleichtert die Fehlersuche.

Git und GitHub

Git

→ verwaltet Versionen.

GitHub

→ stellt Git-Projekte im Internet bereit.

Merke

Git ist das Werkzeug.

GitHub ist die Plattform.

Repository

Ein Projekt auf GitHub heißt Repository.

Ein Repository enthält

  • Dateien,
  • Ordner,
  • Bilder,
  • Programme,
  • Dokumentationen.

Beispiel

Informatik/

README.md

Klasse_9/

Klasse_10/

Material/

README

Fast jedes Repository besitzt eine Datei

README.md

Sie erklärt den Inhalt des Projektes.

Merke

Ein Repository ist der Projektordner auf GitHub.

Dateien bearbeiten

Dateien können

  • gelesen,
  • verändert,
  • hinzugefügt,
  • gelöscht

werden.

Markdown

In diesem Lehrwerk verwenden wir Markdown.

Markdown eignet sich besonders gut für

  • Dokumentationen,
  • Lehrwerke,
  • Webseiten.

Vorteile

  • einfach
  • übersichtlich
  • plattformunabhängig
  • versionsfähig

Branches

Ein Branch ist eine Arbeitskopie.

Dort können Änderungen ausprobiert werden,

ohne das eigentliche Projekt zu verändern.

Vorteile

  • sicher testen
  • gemeinsam arbeiten
  • Experimente durchführen

Merke

Erst nach einer Prüfung werden Änderungen übernommen.

Pull Requests

Ein Pull Request schlägt Änderungen vor.

Andere Personen prüfen diese Änderungen.

Anschließend werden sie

  • angenommen,
  • verbessert oder
  • abgelehnt.

Warum?

Vier Augen sehen mehr als zwei.

Viele Fehler werden dadurch früh entdeckt.

Merke

Ein Pull Request verbessert die Qualität eines Projektes.

Issues

Issues sammeln

  • Fehler,
  • Wünsche,
  • Ideen,
  • Verbesserungen.

Beispiel

Titel

Fehler im Arbeitsblatt 3

Beschreibung

Aufgabe 4 enthält einen Tippfehler.

Merke

Ein Issue beschreibt ein Problem.

Noch keine Lösung.

Open Source

Open Source bedeutet,

dass Programme oder Materialien offen entwickelt werden.

Viele Menschen arbeiten gemeinsam daran.

Vorteile

  • Zusammenarbeit
  • Transparenz
  • Verbesserungen
  • Wiederverwendung

OER

Open Educational Resources

sind offene Bildungsmaterialien.

Auch dieses Lehrwerk gehört dazu.

Merke

Offene Projekte leben von der Mitarbeit vieler Menschen.
