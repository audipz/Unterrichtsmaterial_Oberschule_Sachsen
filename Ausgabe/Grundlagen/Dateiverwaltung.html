Dateiverwaltung

Computer speichern Informationen in Dateien und Ordnern.

Wer Dateien gut organisiert, findet Informationen schneller wieder und vermeidet Datenverlust.

Dieses Kapitel vermittelt grundlegende Kenntnisse zum Umgang mit Dateien und Ordnern.

Dateien

Eine Datei speichert Informationen.

Jede Datei besitzt

  • einen Namen,
  • eine Dateiendung,
  • einen Speicherort.

Beispiele

  • Texte
  • Bilder
  • Musik
  • Videos
  • Programme

Beispiele für Dateien

Hausaufgabe.docx

Ferien.jpg

Programm.py

Projekt.sb3

Merke

Eine Datei enthält Informationen.

Ordner

Ordner helfen dabei,

Dateien übersichtlich zu speichern.

Beispiel

Informatik/

├── Arbeitsheft/

├── Projekte/

├── Bilder/

└── Programme/

Vorteile

  • bessere Übersicht

  • schnelleres Finden

  • weniger Fehler

Merke

Ein guter Ordner spart Zeit.

Dateinamen

Ein guter Dateiname beschreibt den Inhalt.

Gut

Algorithmus_Kakao.md

Python_Uebung_03.py

Schulfest_Planung.docx

Ungünstig

Neu.docx

Test2.docx

abc.txt

Empfehlungen

  • keine Sonderzeichen
  • keine Leerzeichen
  • kurze Namen
  • aussagekräftige Namen

Merke

Dateinamen sollten auch nach mehreren Monaten verständlich sein.

Dateiendungen

Die Dateiendung beschreibt den Dateityp.

Endung Bedeutung
.txt Text
.md Markdown
.docx Word
.pdf PDF
.png Bild
.jpg Bild
.py Python
.sb3 Scratch
.xlsx Excel

Merke

Die Dateiendung gehört zum Dateinamen.

Speichern

Speichere deine Arbeit regelmäßig.

Vorgehensweise

  1. Speicherort auswählen.

  2. Dateinamen vergeben.

  3. Speichern.

Tipp

Lege für jedes Unterrichtsfach einen eigenen Ordner an.

Merke

Nicht gespeicherte Änderungen gehen verloren.

Backup

Ein Backup ist eine Sicherheitskopie.

Warum?

Computer können

  • ausfallen,
  • gestohlen werden,
  • beschädigt werden.

Möglichkeiten

  • USB-Stick

  • externe Festplatte

  • Schulserver

  • Cloudspeicher

3-2-1-Regel

Eine bewährte Strategie:

  • 3 Kopien
  • 2 verschiedene Speichermedien
  • 1 Kopie an einem anderen Ort

Merke

Ein Backup schützt vor Datenverlust.
