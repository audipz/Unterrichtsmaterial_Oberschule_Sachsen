Markdown

Markdown ist eine einfache Auszeichnungssprache.

Mit Markdown können Dokumente geschrieben werden, ohne komplizierte Textverarbeitungsprogramme zu verwenden.

Dieses Lehrwerk wird vollständig in Markdown entwickelt.

Was ist Markdown?

Markdown ist eine leicht lesbare Auszeichnungssprache.

Sie wird verwendet für

  • Dokumentationen
  • Webseiten
  • Wikis
  • Lehrwerke
  • README-Dateien

Vorteile

  • leicht zu lernen
  • plattformunabhängig
  • gut lesbar
  • ideal für GitHub

Merke

Markdown beschreibt Inhalte.

Nicht das Aussehen.

Überschriften

Markdown verwendet das Zeichen

#

Beispiele

# Überschrift 1

## Überschrift 2

### Überschrift 3

Empfehlung

Pro Dokument

nur eine

# Überschrift

verwenden.

Weitere Gliederungen erfolgen mit

##

###

Text

Kursiv

*Text*

Ergebnis

Code

`print()`

Ergebnis

print()

Codeblock

print(“Hallo”)

Merke

Code sollte immer als Code formatiert werden.

Listen

Aufzählung

- Apfel
- Birne
- Banane

Nummerierung

1. Start
2. Bearbeiten
3. Ende

Empfehlung

Listen erhöhen die Lesbarkeit.

Tabellen

|----------|-----|

Quellcode

Markdown unterstützt viele Programmiersprachen.

Python

print("Hallo")

Java

System.out.println("Hallo");

HTML

<h1>Hallo</h1>

Merke

Die Programmiersprache sollte angegeben werden.

GitHub Markdown

GitHub erweitert Markdown um zusätzliche Funktionen.

Aufgabenlisten

- [ ] offen

- [x] erledigt

Tabellen

werden automatisch formatiert.

Emojis

🙂

Hinweise

GitHub unterstützt außerdem

  • Syntaxhervorhebung
  • automatische Inhaltsverzeichnisse
  • Verlinkungen zwischen Dateien

Merke

GitHub erweitert Markdown sinnvoll.
