# Was ist Markdown?

Markdown ist eine leicht lesbare Auszeichnungssprache.

Sie wird verwendet für

- Dokumentationen
- Webseiten
- Wikis
- Lehrwerke
- README-Dateien

---

## Vorteile

- leicht zu lernen
- plattformunabhängig
- gut lesbar
- ideal für GitHub

---

## Merke

Markdown beschreibt Inhalte.

Nicht das Aussehen.

# Überschriften

Markdown verwendet das Zeichen

```
#
```

---

## Beispiele

```
# Überschrift 1

## Überschrift 2

### Überschrift 3
```

---

## Empfehlung

Pro Dokument

nur eine

```
# Überschrift
```

verwenden.

Weitere Gliederungen erfolgen mit

```
##

###
```

# Formatierungen

## Fett

```
**Text**
```

Ergebnis

**Text**

---

## Kursiv

```
*Text*
```

Ergebnis

*Text*

---

## Code

```
`print()`
```

Ergebnis

`print()`

---

## Codeblock
print("Hallo")

---

## Merke

Code sollte immer als Code formatiert werden.



# Listen

## Aufzählung

```
- Apfel
- Birne
- Banane
```

---

## Nummerierung

```
1. Start
2. Bearbeiten
3. Ende
```

---

## Empfehlung

Listen erhöhen die Lesbarkeit.

# Tabellen

Beispiel

```
| Sprache | Typ |
|----------|-----|
| Python | Text |
| Scratch | Blöcke |
```

---

## Ergebnis

| Sprache | Typ |
|----------|------|
| Python | Text |
| Scratch | Blöcke |

---

## Merke

Tabellen eignen sich gut für Vergleiche.

# Bilder und Links

## Link

```
https://example.org
```

---

## Markdown-Link

```
[OpenAI](https://openai.com)
```

---

## Bild

```
![Beschreibung](bild.png)
```

---

## Merke

Jedes Bild benötigt eine Beschreibung.

# Quellcode

Markdown unterstützt viele Programmiersprachen.

---

## Python

```python
print("Hallo")
```

---

## Java

```java
System.out.println("Hallo");
```

---

## HTML

```html
<h1>Hallo</h1>
```

---

## Merke

Die Programmiersprache sollte angegeben werden.

# GitHub Markdown

GitHub erweitert Markdown um zusätzliche Funktionen.

---

## Aufgabenlisten

```
- [ ] offen

- [x] erledigt
```

---

## Tabellen

werden automatisch formatiert.

---

## Emojis

```
:smile:
```

🙂

---

## Hinweise

GitHub unterstützt außerdem

- Syntaxhervorhebung
- automatische Inhaltsverzeichnisse
- Verlinkungen zwischen Dateien

---

## Merke

GitHub erweitert Markdown sinnvoll.

# Markdown Cheat Sheet

| Funktion | Markdown |
|-----------|----------|
| Überschrift | # |
| Fett | **Text** |
| Kursiv | *Text* |
| Code | `Code` |
| Liste | - |
| Nummerierung | 1. |
| Link | [Text](URL) |
| Bild | ![Text](Bild) |
| Tabelle | \| \| |
| Codeblock | ``` |

---

## Tipp

Lerne zunächst nur

- Überschriften
- Listen
- Codeblöcke

Den Rest lernst du mit der Zeit.
