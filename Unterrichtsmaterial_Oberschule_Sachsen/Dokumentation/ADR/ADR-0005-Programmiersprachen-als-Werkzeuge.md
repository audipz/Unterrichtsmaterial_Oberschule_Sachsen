# ADR-0005 – Programmiersprachen sind Werkzeuge

## Status

Akzeptiert

## Kontext

Algorithmen und Problemlösungsstrategien sind nicht an eine bestimmte Programmiersprache gebunden.

## Entscheidung

Das Lehrwerk trennt konsequent zwischen Problem, Algorithmus und Umsetzung.

Programmiersprachen sind Wege zur Umsetzung eines Algorithmus.

Scratch und Python werden bevorzugt eingesetzt, weil sie unterschiedliche Darstellungsformen sichtbar machen:

- Scratch: blockbasiert
- Python: textbasiert

Die zugrunde liegenden Konzepte sollen so formuliert werden, dass sie auch auf andere Sprachen wie BASIC, VBA, Java oder C# übertragbar bleiben.

## Konsequenzen

Syntax wird nur eingeführt, wenn sie für eine konkrete Lösung benötigt wird.

Formulierungen wie „Lerne Python“ werden möglichst vermieden. Stattdessen wird ein Algorithmus „in Python umgesetzt“ oder „mit Python dargestellt“.

Bei späteren Themen wie Objektorientierung kann die Wahl der Sprache stärker fachlich relevant werden.
