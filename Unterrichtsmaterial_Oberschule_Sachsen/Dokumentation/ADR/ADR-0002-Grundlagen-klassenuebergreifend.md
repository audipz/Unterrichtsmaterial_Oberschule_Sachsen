# ADR-0002 – Grundlagen sind klassenübergreifend

## Status

Akzeptiert

## Kontext

Themen wie Scratch, Python, GitHub, Markdown, VS Code, Datenschutz oder Dateiverwaltung werden in mehreren Klassenstufen benötigt.

## Entscheidung

Der Bereich `Grundlagen/` liegt oberhalb der Klassenstufen.

Aktuell vorgesehene Bereiche sind:

- Computer
- Dateiverwaltung
- Datenschutz
- GitHub
- Glossar
- KI
- Lizenzen
- Markdown
- Python
- Scratch
- VSCode

Die Grundlagen erklären Werkzeuge und Basiswissen. Lehrplaninhalte wie Algorithmierung, Verzweigungen oder Wiederholungen gehören nicht in diesen Bereich.

## Konsequenzen

Grundlagen können als Nachschlagewerk genutzt werden, ohne Unterrichtsinhalte zu duplizieren.

Fachkapitel konzentrieren sich auf informatische Konzepte und verweisen bei Bedarf auf die Grundlagen.
