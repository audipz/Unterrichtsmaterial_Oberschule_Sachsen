# Architecture Decision Records (ADR)

Dieser Ordner dokumentiert grundlegende Architekturentscheidungen des OER-Lehrwerks.

ADR-Dokumente erklären nicht nur **was** entschieden wurde, sondern auch **warum**.

## Statuswerte

- `Vorgeschlagen`
- `Akzeptiert`
- `Ersetzt`
- `Verworfen`

## Regel

Bestehende ADRs werden nicht stillschweigend umgeschrieben. Ändert sich eine grundlegende Entscheidung, wird eine neue ADR erstellt und die alte als `Ersetzt` gekennzeichnet.
