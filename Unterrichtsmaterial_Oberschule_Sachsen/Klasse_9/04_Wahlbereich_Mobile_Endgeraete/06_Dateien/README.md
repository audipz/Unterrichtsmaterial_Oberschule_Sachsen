# Dateien – Mobile Endgeräte

Für den Grundkurs sind keine externen Schülerdateien erforderlich. Die Fallanalysen sind vollständig in `03_Material` beschrieben.

Wer eigene Screenshots von Einstellungsdialogen einsetzt, sollte persönliche Konten, Namen, IDs und andere personenbezogene Angaben vor der Verwendung entfernen und die Darstellung auf die jeweilige Geräte-/Systemversion prüfen.
