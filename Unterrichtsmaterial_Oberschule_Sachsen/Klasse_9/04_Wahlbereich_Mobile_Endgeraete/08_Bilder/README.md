# Bilder – Mobile Endgeräte

Der Wahlbereich benötigt keine personenbezogenen Beispielbilder. Für Präsentationen bevorzugt:

- schematische Smartphone-/App-Darstellungen,
- selbst erstellte abstrahierte Berechtigungsdialoge,
- selbst erstellte Symbole für Datenschutz, Updates, Sperrcode, Werbung und Kommunikation.

Bei Screenshots realer Apps oder Betriebssysteme Quelle, Lizenz/Nutzungsrecht und Aktualität dokumentieren. Persönliche Daten vor Verwendung vollständig entfernen.
