# Dateien – Computergrafik

Für den Grundkurs sind keine externen Bilddateien zwingend erforderlich. Die in `03_Material` beschriebenen Fälle können mit selbst erstellten bzw. lizenzrechtlich geeigneten Beispielbildern umgesetzt werden.

Für den Ausschnitt-Vergleich sollte bevorzugt **dieselbe Ausgangsaufnahme** in zwei unterschiedlichen Zuschnitten verwendet werden, damit klar wird: Irreführung kann auch ohne erfundene Pixel entstehen.
