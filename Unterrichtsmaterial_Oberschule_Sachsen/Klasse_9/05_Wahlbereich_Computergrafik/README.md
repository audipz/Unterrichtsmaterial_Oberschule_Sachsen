# Wahlbereich 3 – Computergrafik

## Lehrplanbezug

Möglichkeiten der Manipulation digitaler Bilder werden untersucht. Fotos werden hinsichtlich Authentizität interpretiert und die gesellschaftliche Wirkung manipulierter Bilder bis hin zu Fake News beurteilt.

## Umfang

2–4 Einzelstunden.

## Lernweg

1. Bearbeitung oder Manipulation? Begriffe und Absichten
2. Ausschnitt, Helligkeit, Retusche, Montage und generative Veränderungen
3. Authentizität prüfen: Quelle, Kontext, Zeitpunkt, Rückwärtssuche als Strategie
4. Wirkung manipulierter Bilder auf Meinungsbildung

## Auftrag

Analysiere zwei Versionen desselben Bildes mit unterschiedlichem Ausschnitt. Beschreibe, wie sich die Aussage verändert, obwohl kein Pixel „gefälscht“ sein muss.

## Prüfstrategie

Formuliere eine Checkliste mit mindestens fünf Schritten, bevor ein überraschendes Bild weitergeteilt wird.
