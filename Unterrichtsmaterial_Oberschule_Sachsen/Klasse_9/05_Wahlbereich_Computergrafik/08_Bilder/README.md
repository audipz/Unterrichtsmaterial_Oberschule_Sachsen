# Bilder – Computergrafik

Für die spätere Präsentation werden besonders benötigt:

1. ein selbst erstelltes oder geeignet lizenziertes Ausgangsbild in zwei unterschiedlichen Ausschnitten,
2. ein didaktisches Beispiel für Retusche oder Montage,
3. eine schematische Prüfkette `Quelle → Kontext → Zeitpunkt/Ort → weitere Quellen → ältere Fundstellen`,
4. ggf. ein generativ erstelltes Beispiel, das ausdrücklich als solches gekennzeichnet ist.

Jedes Unterrichtsbild benötigt eine nachvollziehbare Quellen-/Lizenzangabe. Bei selbst erstellten Demonstrationen kenntlich machen, welche Veränderung vorgenommen wurde.
