# Lernkontrollen

Die Lernkontrollen prüfen algorithmische Grundkompetenzen.

Sie können genutzt werden als:

- kurze Lernstandsdiagnose,
- Übung vor der Komplexaufgabe,
- benotete Lernkontrolle nach Anpassung an die Lerngruppe.

Die Projektkompetenzen der eigentlichen Komplexaufgabe sollten zusätzlich prozessbezogen bewertet werden.
