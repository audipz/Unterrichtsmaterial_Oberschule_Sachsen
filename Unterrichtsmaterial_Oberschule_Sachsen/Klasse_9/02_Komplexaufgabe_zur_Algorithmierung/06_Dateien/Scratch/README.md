# Scratch-Beispiele

Die Scratch-Beispiele werden zunächst als Blockbeschreibungen bereitgestellt.

Dadurch bleiben sie unabhängig von einer bestimmten Scratch-Dateiversion und können von den Lernenden selbst aufgebaut werden.

## 01 Begrüßung

```text
Wenn grüne Flagge angeklickt
sage [Willkommen auf unserem Schulfest!]
```

## 02 Begrüßung erweitert

```text
Wenn grüne Flagge angeklickt
sage [Willkommen auf unserem Schulfest!] für 2 Sekunden
sage [Ich bin KAI.] für 2 Sekunden
sage [Viel Spaß!] für 2 Sekunden
```

## 03 Fehlerhafte Reihenfolge

```text
Wenn grüne Flagge angeklickt
sage [Auf Wiedersehen!] für 2 Sekunden
sage [Willkommen!] für 2 Sekunden
```

### Aufgabe

Erkläre den Fehler und verbessere den Ablauf.
