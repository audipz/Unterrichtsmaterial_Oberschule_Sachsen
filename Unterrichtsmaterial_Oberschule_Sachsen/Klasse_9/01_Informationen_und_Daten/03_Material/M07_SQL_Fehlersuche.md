# M07 – SQL-Fehlersuche

Findet die Fehler.

## A

```sql
SELECT Name
Schueler;
```

## B

```sql
UPDATE Schueler
Name = 'Mia'
WHERE SchuelerID = 1;
```

## C

```sql
DELETE Schueler
WHERE SchuelerID = 1;
```

## D

```sql
SELECT *
FROM Schueler
WHERE Name = Mia;
```

## E

```sql
UPDATE Schueler
SET KlasseID = 2;
```

### Zusatzfrage

Die letzte Anweisung ist syntaktisch korrekt. Warum kann sie trotzdem gefährlich sein?
