# M06 – SQL-Befehlskarten

## SELECT

Daten lesen.

```sql
SELECT Name
FROM Schueler;
```

---

## WHERE

Daten filtern.

```sql
WHERE KlasseID = 1
```

---

## ORDER BY

Daten sortieren.

```sql
ORDER BY Name ASC
```

---

## INSERT

Datensatz anlegen.

```sql
INSERT INTO ...
VALUES (...);
```

---

## UPDATE

Datensatz ändern.

```sql
UPDATE ...
SET ...
WHERE ...;
```

---

## DELETE

Datensatz löschen.

```sql
DELETE FROM ...
WHERE ...;
```

---

## CREATE TABLE

Tabelle anlegen.

```sql
CREATE TABLE ...
```

---

## Aufgabe

Erstellt aus mehreren Karten eine sinnvolle SQL-Abfrage.
