# Prüfliste für neue Quellen

Vor der Aufnahme einer neuen Quelle prüfen:

- [ ] Ist die Quelle fachlich zuverlässig?
- [ ] Ist möglichst eine Primärquelle verfügbar?
- [ ] Ist der Titel korrekt angegeben?
- [ ] Ist die URL vollständig?
- [ ] Wurde das Abrufdatum dokumentiert?
- [ ] Ist die Lizenz oder Nutzungsbedingung bekannt?
- [ ] Werden keine unzulässigen Text- oder Bildkopien übernommen?
- [ ] Ist erkennbar, welche Inhalte selbst erstellt wurden?
- [ ] Sind Änderungen an fremden OER-Inhalten gekennzeichnet?
- [ ] Ist die Namensnennung vollständig?
