# Python in VS Code

Nach der Installation der Python-Erweiterung können Programme direkt ausgeführt werden.

---

## Vorgehen

1. Neue Datei anlegen.

2. Als

```
programm.py
```

speichern.

3. Programm schreiben.

4. Ausführen.

---

## Beispiel

```python
print("Hallo Welt!")
```

---

## Merke

VS Code erkennt Python-Dateien automatisch.
