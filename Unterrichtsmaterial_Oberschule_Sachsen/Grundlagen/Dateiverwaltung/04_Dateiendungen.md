# Dateiendungen

Die Dateiendung beschreibt den Dateityp.

---

| Endung | Bedeutung |
|---------|-----------|
| .txt | Text |
| .md | Markdown |
| .docx | Word |
| .pdf | PDF |
| .png | Bild |
| .jpg | Bild |
| .py | Python |
| .sb3 | Scratch |
| .xlsx | Excel |

---

## Merke

Die Dateiendung gehört zum Dateinamen.
