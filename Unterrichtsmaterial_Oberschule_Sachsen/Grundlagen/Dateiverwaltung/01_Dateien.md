# Dateien

Eine Datei speichert Informationen.

Jede Datei besitzt

- einen Namen,
- eine Dateiendung,
- einen Speicherort.

---

## Beispiele

- Texte
- Bilder
- Musik
- Videos
- Programme

---

## Beispiele für Dateien

```
Hausaufgabe.docx

Ferien.jpg

Programm.py

Projekt.sb3
```

---

## Merke

Eine Datei enthält Informationen.
