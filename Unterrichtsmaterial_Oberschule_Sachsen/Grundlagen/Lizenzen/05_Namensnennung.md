# Namensnennung

Viele offene Lizenzen verlangen,

dass der Urheber genannt wird.

---

## Eine vollständige Quellenangabe enthält

- Autor
- Titel
- Quelle
- Lizenz

---

## Beispiel

```
Autor

Titel

Quelle

CC BY-SA 4.0
```

---

## Merke

Eine Quellenangabe zeigt Respekt vor der Arbeit anderer.
