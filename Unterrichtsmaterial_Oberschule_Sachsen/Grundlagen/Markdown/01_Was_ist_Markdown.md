# Was ist Markdown?

Markdown ist eine leicht lesbare Auszeichnungssprache.

Sie wird verwendet für

- Dokumentationen
- Webseiten
- Wikis
- Lehrwerke
- README-Dateien

---

## Vorteile

- leicht zu lernen
- plattformunabhängig
- gut lesbar
- ideal für GitHub

---

## Merke

Markdown beschreibt Inhalte.

Nicht das Aussehen.
