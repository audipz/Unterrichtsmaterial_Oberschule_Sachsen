# Markdown Cheat Sheet

| Funktion | Markdown |
|-----------|----------|
| Überschrift | # |
| Fett | **Text** |
| Kursiv | *Text* |
| Code | `Code` |
| Liste | - |
| Nummerierung | 1. |
| Link | [Text](URL) |
| Bild | ![Text](Bild) |
| Tabelle | \| \| |
| Codeblock | ``` |

---

## Tipp

Lerne zunächst nur

- Überschriften
- Listen
- Codeblöcke

Den Rest lernst du mit der Zeit.
