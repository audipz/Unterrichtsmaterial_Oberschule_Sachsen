# Debugging

Debugging bedeutet,

Programme systematisch zu überprüfen.

---

## Vorgehensweise

1. Programm starten.
2. Fehler beobachten.
3. Ursache suchen.
4. Fehler beheben.
5. Erneut testen.

---

## Tipp

Ändere immer nur eine Stelle.

So erkennst du leichter,

welche Änderung geholfen hat.

---

## Merke

Testen gehört zum Programmieren dazu.
