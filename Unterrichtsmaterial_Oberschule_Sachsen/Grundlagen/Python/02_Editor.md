# Der Editor

Ein Editor dient zum Schreiben von Programmen.

Er unterstützt dich beim Programmieren.

---

## Bestandteile

- Menü
- Editor
- Ausgabefenster
- Fehlermeldungen

---

## Vorteile

Der Editor

- färbt Befehle ein,
- erkennt viele Fehler,
- erleichtert das Schreiben.

---

## Merke

Der Editor führt dein Programm nicht aus.

Er hilft dir beim Schreiben.
