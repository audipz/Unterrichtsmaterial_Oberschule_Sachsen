# Pull Requests

Ein Pull Request schlägt Änderungen vor.

Andere Personen prüfen diese Änderungen.

Anschließend werden sie

- angenommen,
- verbessert oder
- abgelehnt.

---

## Warum?

Vier Augen sehen mehr als zwei.

Viele Fehler werden dadurch früh entdeckt.

---

## Merke

Ein Pull Request verbessert die Qualität eines Projektes.
