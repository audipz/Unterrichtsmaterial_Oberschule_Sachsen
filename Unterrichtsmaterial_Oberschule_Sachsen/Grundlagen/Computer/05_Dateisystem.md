# Dateisystem

Das Dateisystem organisiert Dateien.

Es sorgt dafür,

dass Dateien gespeichert und wiedergefunden werden können.

---

## Aufbau

```
Dokumente

├── Informatik

├── Mathematik

└── Bilder
```

---

## Vorteile

- Ordnung
- Übersicht
- schnelles Finden

---

## Merke

Eine gute Ordnerstruktur spart Zeit.
