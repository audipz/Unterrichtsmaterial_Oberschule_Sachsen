# M01 – Datenmengenvergleich Computergrafik

## Gegeben
Verglichen werden zwei unkomprimierte RGB-Einzelbilder mit 24 Bit Farbtiefe.

| Variante | Auflösung | Pixelzahl | Rohdaten |
|---|---:|---:|---:|
| A | 640 × 480 |  |  |
| B | 1920 × 1080 |  |  |

## Arbeitsauftrag
1. Berechne die Pixelzahl.
2. Berechne die Rohdatenmenge in Byte und MiB.
3. Bestimme den Faktor B : A.
4. Überlege, was bei 60 Bildern pro Sekunde zusätzlich berücksichtigt werden muss.
5. Markiere mögliche Engpässe: GPU, RAM/VRAM, Massenspeicher, Datenbus, Netzwerk.

## Transferfrage
Ein Stream sieht trotz hoher Bildschirmauflösung zeitweise unscharf aus. Erkläre, warum geringere Datenrate bzw. stärkere Kompression dafür eine plausible Ursache sein kann.
