# Wahlbereich 1 – Steuern und Regeln

## Lehrplanbezug

Programmierkenntnisse werden auf die Steuerung von Endgeräten mit Sensoren übertragen. Begriffe: Steuerung, Regelung, Sensor, Aktor.

## Umfang

2–4 Einzelstunden.

## Lernweg

1. Sensoren erfassen Zustände, Aktoren wirken auf die Umwelt
2. Steuerung und Regelung unterscheiden
3. Ampel, Heizung oder Roboter als System modellieren
4. Algorithmus für ein Sensor-Aktor-System entwickeln und testen

## Praxisauftrag

Entwirf eine automatische Beleuchtung: Ein Helligkeitssensor liefert einen Wert. Unterhalb eines Grenzwertes wird eine Lampe eingeschaltet. Ergänze anschließend eine Verbesserung, die häufiges Ein-/Ausschalten am Grenzwert verhindert.
