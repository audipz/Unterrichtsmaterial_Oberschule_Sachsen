# Lehrplanabgleich – Netzwerke in der Informatik

## Stand

Grundlage ist der sächsische Lehrplan Oberschule Informatik 2022, Klassenstufe 8, Lernbereich 2 „Netzwerke in der Informatik“ mit 10 Unterrichtsstunden.

## Abdeckung

- [x] Aufbau und Struktur von Netzwerken
- [x] Datenübertragung und Bedeutung von Netzwerken
- [x] LAN, WLAN, Intranet, Internet
- [x] Einbindung verschiedener Endgeräte
- [x] Server, Client, Router, Switch, Accesspoint
- [x] IP-Adressen und DNS grundlegend
- [x] Kupfer, Lichtwellenleiter, Funk
- [x] Netzwerkprotokolle HTTP, FTP, Mail
- [x] Dienste WWW und Mail
- [x] systematische Untersuchung von Datenwegen und Fehlerfällen
- [x] historische Kryptografie
- [x] Klartext, Geheimtext, Schlüssel
- [x] einfache symmetrische Verschlüsselung
- [x] Gegenwartsbezug zu Passwortschutz und Einwegfunktionen

## Noch offen

- [ ] PPTX aus dem Präsentations-MD erstellen
- [ ] ausführliche Lehrerbemerkungen in der PPTX ergänzen
- [ ] eigene Netzwerkdiagramme/Grafiken in der PPTX ergänzen und als eigene Darstellung kennzeichnen
- [ ] Unterrichtssequenz nach Praxissichtung zeitlich feinjustieren
