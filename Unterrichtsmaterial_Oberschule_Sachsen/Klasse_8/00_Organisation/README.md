# Klasse 8 – Organisation

Die Pflichtlernbereiche 01–04 verwenden einheitlich `01_Arbeitsheft`, `02_Lehrerband`, `03_Material`, `04_Loesungen` und `05_Praesentationen`. Die Wahlbereiche 06–08 erhalten ebenfalls Arbeitsheft, Lehrerhinweise und Lösungen. PowerPoint-Dateien werden bewusst in einem nachfolgenden Arbeitsschritt überarbeitet.

## Reihenfolge
01 Objektorientierte Modellierung · 02 Algorithmen · 03 Robot Karol · 04 Netzwerke · 05 Leistungskontrollen · 06 Steuern und Regeln · 07 Mobile Endgeräte · 08 Computergrafik.

## Qualitätsregel
Zu einer Unterrichtsaufgabe gehören eine eindeutige Aufgabenstellung, ein erwartbares Ergebnis und – sofern sinnvoll – Lehrerhinweise bzw. eine Lösung. Präsentationen ergänzen diese Materialien, ersetzen sie aber nicht.
