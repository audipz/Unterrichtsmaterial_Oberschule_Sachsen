# Wahlbereich 3 – Computergrafik

## Lehrplanbezug

Programmierkenntnisse werden auf die Erstellung von Vektorgrafiken übertragen. Im Mittelpunkt stehen Muster und Ornamente.

## Umfang

2–4 Einzelstunden.

## Lernweg

1. Grundform als grafisches Objekt
2. Wiederholung durch Schleifen
3. Position, Drehung, Größe und Farbe als veränderbare Attribute
4. Muster und Ornamente algorithmisch erzeugen

## Programmierauftrag

Erzeuge ein Ornament aus einer Grundform. Nutze mindestens eine Schleife und verändere pro Wiederholung mindestens ein Attribut. Dokumentiere den Algorithmus zuerst als Struktogramm oder Pseudocode und anschließend mit einem Screenshot der fertigen Grafik.

## Reflexion

Welche Teile des Bildes sind Daten, welche Teile Algorithmus?
