# Lösungen – Objektorientierung

## Zuordnung

`Hund` = Klasse, `Bello` = Objekt, `Fellfarbe` = Attribut, `braun` = Attributwert, `Auto` = Klasse, `Kennzeichen` = Attribut, `DD-AB 123` = Attributwert.

## Beispiel Smartphone_A

Klasse `Smartphone`; Attribute z. B. `farbe=schwarz`, `speicher=128 GB`, `akku=73 %`, `lautstaerke=40 %`, `wlan=aktiv`.

## Fehleraufgabe

`Auto_17` bezeichnet typischerweise ein konkretes Objekt. `Auto` ist die Klasse. Ein Attributwert gehört zu einem benannten Attribut, etwa `farbe=blau`.

## Methoden und Zustände

Mögliche Klasse `Roboter`: Attribute `position`, `richtung`, `hatMarke`, `anzahlZiegel`; Methoden `schritt()`, `linksDrehen()`, `hinlegen()`, `aufheben()`, `markeSetzen()`.

`aufschliessen()` kann `verschlossen` auf `nein` setzen. `oeffnen()` kann anschließend `offen` auf `ja` setzen. Eine sinnvolle Bedingung lautet: Öffnen nur, wenn `verschlossen = nein`.
