# M07 – Systembereitschaft und Dateioperationen

## Auftrag A – System bereit machen

Arbeite an einem Schul-PC oder einem vergleichbaren Übungsgerät. Dokumentiere kurz:

1. Gerät einschalten oder Sitzung starten.
2. Anmeldung durchführen.
3. Verbindung zum Schulnetz, Netzlaufwerk oder zur Lernplattform prüfen.
4. Benötigte Anwendung öffnen.
5. Eine vorgegebene Datei öffnen.
6. Eine Kopie unter sinnvollem Namen speichern.

## Auftrag C – Kopieren oder Verschieben?

Entscheide jeweils, ob Kopieren oder Verschieben sinnvoll ist.

1. Eine Sicherheitskopie auf einem USB-Stick anlegen.
2. Eine Datei aus `Downloads` in den Projektordner einsortieren.
3. Eine Vorlage für mehrere Gruppen bereitstellen.
4. Eine falsch abgelegte Datei an den richtigen Ort bringen.

## Sicherung

> Systembereitschaft bedeutet: Gerät, Anmeldung, Verbindung, Anwendung und benötigte Dateien sind nutzbar. Meldungen geben Hinweise und sollten fachlich gelesen werden.
