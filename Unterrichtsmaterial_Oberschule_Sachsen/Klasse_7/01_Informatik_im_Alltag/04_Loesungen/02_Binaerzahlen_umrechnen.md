# Lösungen – 02 Binärzahlen umrechnen

## Arbeitsheft Aufgabe 1

1. `5₁₀ = 101₂`
2. `9₁₀ = 1001₂`
3. `12₁₀ = 1100₂`
4. `18₁₀ = 10010₂`
5. `27₁₀ = 11011₂`

Beispiele Zerlegung:

```text
12 = 8 + 4
27 = 16 + 8 + 2 + 1
```

## Arbeitsheft Aufgabe 2

```text
10₁₀ = 1010₂
15₁₀ = 1111₂

25₁₀ = 11001₂
```

## Arbeitsheft Aufgabe 3

1. `101₂ = 5₁₀`
2. `1001₂ = 9₁₀`
3. `1110₂ = 14₁₀`
4. `10000₂ = 16₁₀`
5. `11001₂ = 25₁₀`
6. `111111₂ = 63₁₀`

## Arbeitsheft Aufgabe 4

Die Aussage ist falsch.

```text
1111₂ = 8 + 4 + 2 + 1 = 15₁₀
```

Richtig ist:

```text
14₁₀ = 1110₂
```

## Knobelaufgabe

Mit vier Bits:

- kleinste Zahl: `0`
- größte Zahl: `15`
- mögliche Bitmuster: `16`
