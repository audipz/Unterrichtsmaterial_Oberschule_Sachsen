# Lösung – M07 Systembereitschaft und Dateioperationen

## Auftrag A

Die Dokumentation soll zeigen, dass die Schülerinnen und Schüler das System nutzbar machen können: Anmeldung, Verbindung, Anwendung, Datei öffnen und Kopie sinnvoll speichern. Entscheidend sind nachvollziehbare Schritte und ein sinnvoller Dateiname.

## Auftrag B

| Meldung | mögliche Ursache | sinnvolle Reaktion |
|---|---|---|
| Falsches Passwort | Tippfehler, falsches Konto, Feststelltaste | Eingabe prüfen, erneut versuchen, Hilfe holen |
| Keine Netzwerkverbindung | WLAN/LAN getrennt, Server nicht erreichbar | Verbindung prüfen, später erneut versuchen, Lehrkraft informieren |
| Datei ist schreibgeschützt | Vorlage, fehlende Bearbeitungsrechte | Kopie speichern oder Berechtigung klären |
| Keine Berechtigung zum Speichern | falscher Ordner, kein Zugriff | anderen Speicherort wählen, Rechte klären |
| Datei mit diesem Namen existiert bereits | Name schon vergeben | Versionierung nutzen oder bewusst überschreiben, wenn sicher |

## Auftrag C

1. Kopieren – Sicherheitskopie bleibt zusätzlich erhalten.
2. Verschieben – Datei soll in den Projektordner einsortiert werden.
3. Kopieren – Vorlage soll mehrfach verfügbar sein.
4. Verschieben – Datei soll an den richtigen Ort, nicht doppelt bleiben.
