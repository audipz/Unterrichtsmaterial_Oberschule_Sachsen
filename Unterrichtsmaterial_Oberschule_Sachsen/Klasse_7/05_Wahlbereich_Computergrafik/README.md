# Wahlbereich 3 – Computergrafik

## Lehrplanbezug

Objektorientierung wird auf Bildbearbeitung angewendet. Pixel- und Vektorgrafiken werden unterschieden; Pixel und Bildschirmauflösung werden praktisch untersucht.

## Umfang

2–4 Einzelstunden.

## Lernweg

1. Bilder bestehen aus Objekten oder Pixeln
2. Pixelgrafik: Auflösung, Vergrößerung, Qualitätsverlust
3. Vektorgrafik: Objekte, Attribute, Skalierung
4. Gestaltungsaufgabe: Einladung oder Stundenplan

## Produkt

Eine selbst gestaltete Grafik mit kurzer Begründung, warum Pixel- oder Vektorgrafik für die Aufgabe geeignet ist.
