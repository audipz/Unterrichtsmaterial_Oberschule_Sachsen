# Wahlbereich – Computergrafik

## Umfang
2–4 Einzelstunden.

## Lernweg
1. Bilder bestehen aus Pixeln oder grafischen Objekten.
2. Pixelgrafik: Auflösung, Vergrößerung und Qualitätsverlust.
3. Vektorgrafik: Objekte, Attribute und Skalierung.
4. Gestaltungsaufgabe mit begründeter Wahl des Grafiktyps.

## Struktur
- `01_Arbeitsheft`
- `02_Lehrerband`
- `03_Material`
- `04_Loesungen`
- `05_Praesentationen`
- `07_Quellen`
