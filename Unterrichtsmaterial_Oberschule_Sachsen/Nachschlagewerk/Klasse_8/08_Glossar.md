# 8 Glossar

**Abstraktion:** bewusstes Weglassen unwichtiger Einzelheiten in einem Modell.

**Aktor:** Bauteil, das eine Aktion ausführt.

**Algorithmus:** eindeutige Handlungsvorschrift zur Lösung einer Aufgabe.

**Attribut:** Eigenschaft eines Objekts.

**Bedingung:** Ausdruck mit dem Ergebnis wahr oder falsch.

**Client:** Gerät oder Programm, das einen Dienst anfordert.

**DNS:** System zur Zuordnung von Namen zu IP-Adressen.

**IP-Adresse:** Adresse eines Geräts beziehungsweise Anschlusses in einem IP-Netzwerk.

**Klasse:** gemeinsame Beschreibung gleichartiger Objekte.

**LAN:** lokales Netzwerk.

**Methode:** mögliche Operation eines Objekts.

**Objekt:** konkretes Element einer modellierten Welt.

**Regelung:** Beeinflussung eines Systems mithilfe einer Rückkopplung.

**Router:** Gerät zur Weiterleitung von Daten zwischen Netzwerken.

**Sensor:** Bauteil zur Erfassung einer physikalischen Größe.

**Server:** System, das Dienste oder Daten bereitstellt.

**Sollwert:** gewünschter Zielwert.

**Steuerung:** gezielte Beeinflussung eines Ablaufs ohne notwendige Rückkopplung.

**Variable:** benannter Speicherplatz für einen veränderlichen Wert.

**WLAN:** lokales Funknetzwerk.
