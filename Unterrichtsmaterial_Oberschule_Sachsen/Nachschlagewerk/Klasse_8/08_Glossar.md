# 8 Glossar

Dieses Glossar fasst zentrale Begriffe des Nachschlagewerks Klasse 8 zusammen. Ausführliche Erklärungen und Beispiele stehen in den jeweiligen Fachkapiteln.

**Abstraktion:** bewusstes Weglassen unwichtiger Einzelheiten und Hervorheben der für einen Modellierungszweck wichtigen Merkmale.

**Access Point:** Netzwerkkomponente, die drahtlose Geräte mit einem lokalen Netzwerk verbindet.

**Aktor:** Bauteil, das ein Signal in eine physische Wirkung umsetzt, beispielsweise Motor, Lampe oder Ventil.

**Algorithmus:** eindeutige und endliche Handlungsvorschrift zur Lösung einer Klasse von Aufgaben.

**App-Berechtigung:** vom Betriebssystem kontrollierte Erlaubnis für eine App, auf geschützte Daten oder Gerätefunktionen zuzugreifen.

**Assoziation:** allgemeine Beziehung zwischen Objekten beziehungsweise Klassen.

**Attribut:** benannte Eigenschaft eines Objekts.

**Attributwert:** konkreter Wert eines Attributes bei einem bestimmten Objekt.

**Auswahl:** Kontrollstruktur, bei der abhängig von einer Bedingung ein bestimmter Programmzweig ausgeführt wird.

**Ablaufdiagramm / Flussdiagramm:** grafische Darstellung eines Ablaufs mit standardisierten Symbolen und Pfeilen.

**Bedingung:** Ausdruck mit dem Ergebnis wahr oder falsch.

**Bluetooth:** Funktechnik für Verbindungen über kurze Entfernungen.

**Client:** Programm oder System, das einen Dienst nutzt beziehungsweise anfordert.

**Cloud-Dienst:** über ein Netzwerk bereitgestellter Speicher- oder Rechendienst auf entfernten Systemen.

**Datentyp:** Festlegung, welche Art von Werten gespeichert und welche Operationen damit sinnvoll durchgeführt werden können.

**Deklaration:** Bekanntmachen einer Variablen, häufig einschließlich Name und Datentyp.

**DHCP:** Netzwerkprotokoll, das Geräten automatisch IP-Konfigurationen bereitstellen kann.

**DNS:** Domain Name System; verteiltes System, das Domainnamen Informationen wie IP-Adressen zuordnet.

**Domain:** hierarchisch organisierter Name beziehungsweise Namensbereich im Domain Name System.

**Endlosschleife:** Wiederholung ohne wirksame Beendigung; sie kann beabsichtigt oder ein Programmfehler sein.

**Fremdschlüssel:** wird in Klasse 9 bei relationalen Datenbanken vertieft; ein Attribut, das auf einen Schlüssel eines anderen Datensatzes verweisen kann.

**GNSS:** Oberbegriff für globale Satellitennavigationssysteme wie GPS und Galileo.

**Hysterese:** Abstand zwischen unterschiedlichen Ein- und Ausschaltgrenzen, der häufiges Umschalten vermeiden kann.

**Initialisierung:** erstmalige Vergabe eines Anfangswertes an eine Variable beziehungsweise ein Objekt.

**Instanz:** konkretes Objekt einer Klasse.

**IP-Adresse:** Adresse einer Netzwerkschnittstelle in einem IP-Netzwerk.

**Istwert:** aktuell gemessener Wert einer betrachteten Regelgröße.

**Kapselung:** Zusammenfassen von Daten und Verhalten sowie kontrollierter Zugriff auf innere Details eines Objekts.

**Kardinalität:** Angabe, wie viele Objekte an einer Beziehung beteiligt sein können.

**Klasse:** gemeinsame Beschreibung gleichartiger Objekte mit Attributen und Methoden.

**Komposition:** starke Teil-Ganzes-Beziehung in einem objektorientierten Modell.

**Kompression:** Verringerung der zur Speicherung oder Übertragung benötigten Datenmenge.

**Konstruktor:** besondere Operation zur Erzeugung beziehungsweise Initialisierung eines Objekts.

**LAN:** Local Area Network; lokales Netzwerk in einem räumlich begrenzten Bereich.

**Lambda-Ausdruck:** kurze, häufig namenlose Funktion; kein Zuweisungs- oder Vergleichsoperator.

**Methode:** Operation beziehungsweise Verhalten, das einer Klasse oder einem Objekt zugeordnet ist.

**NFC:** Near Field Communication; Funktechnik für Kommunikation über sehr kurze Entfernung.

**Objekt:** konkrete Instanz einer Klasse mit eigener Identität und eigenem Zustand.

**Parameter:** zusätzlicher Wert, der einer Anweisung, Funktion oder Methode beim Aufruf übergeben wird.

**Pixel:** einzelner Bildpunkt einer Rastergrafik.

**Port:** Nummer, mit deren Hilfe TCP- oder UDP-Kommunikation einer Anwendung beziehungsweise einem Dienst zugeordnet werden kann.

**Protokoll:** vereinbarte Regeln für Aufbau, Bedeutung und Ablauf einer Kommunikation.

**Pseudocode:** programmiersprachenunabhängige strukturierte Beschreibung eines Algorithmus.

**Push-Benachrichtigung:** über einen Vermittlungsdienst an eine App beziehungsweise ein Gerät zugestellte Information.

**Rastergrafik:** digitale Grafik, die aus einem Raster einzelner Pixel besteht.

**Regelabweichung:** Differenz zwischen Sollwert und Istwert.

**Regelkreis:** geschlossener Wirkungsablauf einer Regelung mit Rückführung des Istwertes.

**Regelung:** Beeinflussung eines Prozesses mithilfe einer Rückkopplung des gemessenen Ergebnisses.

**Router:** Netzwerkkomponente, die Datenpakete zwischen unterschiedlichen IP-Netzen weiterleitet.

**Rückgabewert:** Ergebnis, das eine Funktion oder Methode an den aufrufenden Programmteil zurückgibt.

**Sandbox:** abgeschotteter Bereich, der Zugriffe einer App oder eines Programms begrenzt.

**Sensor:** Bauteil, das eine physikalische Größe oder einen Zustand erfasst und daraus verarbeitbare Daten erzeugt.

**Sequenz:** Kontrollstruktur, bei der Anweisungen nacheinander ausgeführt werden.

**Server:** Programm oder System, das einen Dienst für andere Teilnehmer bereitstellt.

**Skalieren:** Größe eines Bildes oder grafischen Objekts verändern.

**Sollwert:** gewünschter Zielwert einer Regelgröße.

**Steuerung:** gezielte Beeinflussung eines Ablaufs ohne notwendige Rückkopplung des tatsächlich erreichten Ergebnisses.

**Struktogramm / Nassi-Shneiderman-Diagramm:** grafische Darstellung eines Algorithmus mit verschachtelten Blöcken für Kontrollstrukturen.

**SVG:** Scalable Vector Graphics; textbasiertes Format für skalierbare Vektorgrafiken.

**Switch:** Netzwerkkomponente, die Geräte innerhalb eines lokalen Netzes verbindet und Daten gezielt an passende Anschlüsse weiterleitet.

**Synchronisation:** Abgleich von Datenbeständen zwischen mehreren Systemen; nicht automatisch eine unabhängige Datensicherung.

**TCP:** Transportprotokoll, das Anwendungen unter anderem eine zuverlässige, geordnete Byteübertragung bereitstellt.

**Transparenz:** Eigenschaft einer Grafik, bei der darunterliegende Inhalte ganz oder teilweise sichtbar bleiben.

**UDP:** verbindungsloses Transportprotokoll mit geringem Protokollaufwand, das selbst keine zuverlässige Zustellung garantiert.

**URL:** Adresse beziehungsweise Bezeichner einer Ressource, die unter anderem Schema, Host und Pfad enthalten kann.

**Variable:** benannter Speicherplatz beziehungsweise Name für einen Wert, den ein Algorithmus verwendet und verändern kann.

**Vektorgrafik:** Grafik aus mathematisch beschriebenen Formen und Objekten.

**Vererbung:** objektorientierte Beziehung, bei der eine speziellere Klasse Merkmale einer allgemeineren Klasse übernehmen kann.

**Wiederholung / Schleife:** Kontrollstruktur, die einen Programmabschnitt mehrfach ausführt.

**WLAN:** Technik für lokale drahtlose Netzwerke.

**Zuweisung:** Speichern eines Wertes in einer Variablen; im Pseudocode dieses Nachschlagewerks mit `:=` geschrieben.

**Zustand:** Gesamtheit der aktuellen Attributwerte eines Objekts.
