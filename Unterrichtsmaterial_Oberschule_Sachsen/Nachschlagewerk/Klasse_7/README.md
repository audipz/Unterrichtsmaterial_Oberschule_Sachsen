# Nachschlagewerk Informatik – Klasse 7

Dieses Verzeichnis enthält die modularen Quellen für das Schüler-Nachschlagewerk der Klasse 7. Das vollständige Nachschlagewerk ist dafür vorgesehen, zu Beginn des Schuljahres ausgegeben zu werden.

## Ziel

Das Nachschlagewerk ist kein Arbeitsheft. Es enthält keine Unterrichtsabläufe, Lehrerhinweise, Lösungen oder längeren Arbeitsaufträge. Die Kapitel bereiten Wissen so auf, dass Schülerinnen und Schüler Begriffe, Zusammenhänge und Beispiele selbstständig nachschlagen können.

Typischer Aufbau eines Kapitels:

1. Begriff oder Fragestellung
2. verständliche Erklärung
3. Beispiel oder Tabelle
4. Merksatz
5. Begriffe zum Nachschlagen
6. bei Bedarf Querverweise auf andere Kapitel

## Generierung

Die Datei `manifest.txt` legt Reihenfolge und Auswahl der Kapitel fest. Der Build soll daraus ein zusammenhängendes Nachschlagewerk als PDF, DOCX und HTML erzeugen.

Vorhandene Inhalte aus den Klassenmaterialien, `Grundlagen` und `Werkzeuge` dienen als fachliche Quellen. Sie werden nicht ungeprüft zusammenkopiert, weil Arbeitshefte und Lehrerunterlagen einen anderen Zweck haben.

## Grafiken und Quellen

Didaktische Erklärgrafiken sollen bevorzugt selbst erstellt und als SVG im Repository gepflegt werden. Frei lizenzierte externe Bilder können ergänzt werden, wenn Originalquelle, Urheber und Lizenz eindeutig dokumentiert sind. Für reproduzierbare Builds ist ein kontrollierter Download mit lokalem Cache vorgesehen.
