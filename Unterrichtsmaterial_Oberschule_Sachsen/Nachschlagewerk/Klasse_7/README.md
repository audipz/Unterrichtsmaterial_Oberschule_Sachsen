# Nachschlagewerk Informatik – Klasse 7

Dieses Verzeichnis enthält die modularen Quellen für das Schüler-Nachschlagewerk der Klasse 7.

## Ziel

Das Nachschlagewerk ist kein Arbeitsheft. Es enthält keine Unterrichtsabläufe, Lehrerhinweise, Lösungen oder längeren Arbeitsaufträge. Die Kapitel sollen Wissen so aufbereiten, dass Schülerinnen und Schüler Begriffe, Zusammenhänge und Beispiele selbstständig nachschlagen können.

Typischer Aufbau eines Kapitels:

1. Begriff oder Fragestellung
2. verständliche Erklärung
3. Beispiel oder Tabelle
4. Merksatz
5. bei Bedarf Querverweis auf ein Werkzeug oder ein Grundlagen-Thema

## Generierung

Die Datei `manifest.txt` legt Reihenfolge und Auswahl der Kapitel fest. Der Build soll daraus ein zusammenhängendes Nachschlagewerk als PDF, DOCX und HTML erzeugen.

Vorhandene Inhalte aus den Klassenmaterialien, `Grundlagen` und `Werkzeuge` dienen als fachliche Quellen. Sie werden nicht ungeprüft zusammenkopiert, weil Arbeitshefte und Lehrerunterlagen einen anderen Zweck haben.
