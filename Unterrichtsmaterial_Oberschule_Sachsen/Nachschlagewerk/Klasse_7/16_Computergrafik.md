# 16 Computergrafik

## Raster oder Vektor?

Computergrafiken können auf unterschiedliche Weise beschrieben werden. Zwei wichtige Grundformen sind **Rastergrafiken** und **Vektorgrafiken**.

Rastergrafiken bestehen aus Pixeln. Vektorgrafiken bestehen aus mathematisch beschriebenen Formen wie Linien, Kurven, Kreisen und Flächen.

| Eigenschaft | Rastergrafik | Vektorgrafik |
|---|---|---|
| Aufbau | Pixel | geometrische Formen |
| geeignet für | Fotos, gemalte Bilder | Logos, Symbole, Pläne |
| Vergrößerung | Pixel können sichtbar werden | meist ohne Qualitätsverlust skalierbar |
| typische Formate | PNG, JPEG | SVG |

## Auflösung bei Rastergrafiken

Die Anzahl der Pixel bestimmt, wie viele einzelne Bildpunkte zur Verfügung stehen. Wird eine kleine Rastergrafik stark vergrößert, werden Pixel und Kanten sichtbar.

Eine hohe Auflösung allein garantiert jedoch kein gutes Bild. Unschärfe, schlechte Beleuchtung oder starke Kompression können die Qualität ebenfalls begrenzen.

## Vektorgrafiken

Bei einer Vektorgrafik wird beispielsweise nicht jeder Pixel eines Kreises gespeichert. Stattdessen werden Eigenschaften wie Mittelpunkt, Radius, Linienfarbe und Füllung beschrieben. Das Programm berechnet daraus die Darstellung für die gewünschte Größe.

Deshalb eignen sich Vektorgrafiken besonders für:

- Logos,
- Piktogramme,
- technische Skizzen,
- einfache Illustrationen,
- Diagramme.

## Ebenen

Viele Grafikprogramme verwenden **Ebenen**. Man kann sie sich wie transparente Folien vorstellen, die übereinanderliegen. Elemente auf verschiedenen Ebenen lassen sich getrennt bearbeiten.

## Farben

Für Bildschirme wird häufig RGB verwendet. Beim professionellen Druck begegnet man auch anderen Farbmodellen. Farben können auf verschiedenen Geräten unterschiedlich wirken, weil Displays und Drucker sie auf unterschiedliche Weise erzeugen.

## Transparenz

Ein Bildformat kann transparente Bereiche unterstützen. PNG und SVG können beispielsweise Transparenz speichern. JPEG unterstützt keine transparente Fläche.

## Das richtige Format wählen

| Aufgabe | häufig geeignet |
|---|---|
| Foto | JPEG oder je nach Zweck PNG |
| Logo | SVG |
| Screenshot mit Schrift | PNG |
| skalierbares Symbol | SVG |
| Bild mit Transparenz | PNG oder SVG |

Die konkrete Wahl hängt immer vom Verwendungszweck ab.

> **Merke:** Rastergrafiken speichern Bildpunkte, Vektorgrafiken beschreiben Formen. Das passende Verfahren hängt vom Inhalt ab.

## Begriffe zum Nachschlagen

**Ebene:** getrennt bearbeitbare Schicht innerhalb einer Grafik.

**Rastergrafik:** aus einzelnen Pixeln aufgebautes Bild.

**Skalieren:** Größe einer Grafik verändern.

**Transparenz:** vollständig oder teilweise durchsichtiger Bildbereich.

**Vektorgrafik:** aus mathematisch beschriebenen Formen aufgebaute Grafik.
