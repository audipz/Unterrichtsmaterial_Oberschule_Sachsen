# Mitwirken am Projekt

Vielen Dank für dein Interesse an diesem OER-Projekt!

Ziel ist es, gemeinsam ein qualitativ hochwertiges, freies Unterrichtswerk für das Fach **Informatik an Oberschulen in Sachsen** zu entwickeln.

Jede Unterstützung ist willkommen.

---

# Wie kann ich helfen?

Beiträge sind beispielsweise möglich durch

- Fehlerkorrekturen
- Rechtschreibkorrekturen
- Verbesserungsvorschläge
- neue Aufgaben
- neue Beispiele
- Präsentationen
- Bilder und Grafiken
- Beispielprogramme
- Lehrerhinweise
- Lösungen
- Barrierefreiheit
- Übersetzungen

---

# Grundprinzipien

Alle Beiträge orientieren sich an den Dokumenten im Ordner

```text
Dokumentation/
```

Insbesondere an

- Didaktisches_Konzept.md
- Stilguide.md
- Qualitaetsstandards.md
- Repository_Standards.md
- Quellenleitfaden.md

---

# Didaktische Leitlinien

Alle Unterrichtseinheiten folgen derselben Struktur.

Problem

↓

Fragestellung

↓

Entdecken

↓

Begriff

↓

Anwendung

↓

Transfer

Neue Fachbegriffe werden nicht vorausgesetzt.

---

# Schreibstil

Bitte

- kurze Sätze verwenden,
- verständlich schreiben,
- Fachbegriffe erklären,
- geschlechtergerechte Sprache entsprechend den Projektstandards verwenden,
- Beispiele aus der Lebenswelt nutzen.

---

# Dateibenennung

Dateien beginnen mit einer zweistelligen Nummer.

Beispiel

```text
01_Welche_Informationen_brauchen_wir.md
```

Regeln

- keine Umlaute
- keine Leerzeichen
- Unterstriche verwenden

---

# Markdown

Verwendet ausschließlich Markdown.

Überschriften

```markdown
# Kapitel

## Aufgabe

### Merkkasten
```

---

# Bilder

Bilder sollen

- informativen Charakter besitzen,
- möglichst als SVG vorliegen,
- barrierearm sein,
- eine Quellenangabe besitzen.

---

# Quellen

Jede fachliche Aussage muss nachvollziehbar sein.

Verwendet möglichst

- Lehrpläne
- Fachliteratur
- offizielle Dokumentationen
- wissenschaftliche Veröffentlichungen

---

# KI-Unterstützung

KI darf zur Erstellung von Materialien verwendet werden.

Vor einer Veröffentlichung müssen Inhalte jedoch geprüft werden.

Insbesondere

- Fachlichkeit
- Lehrplankonformität
- Quellen
- Urheberrecht

liegen in der Verantwortung der Beitragenden.

---

# Pull Requests

Vor dem Erstellen eines Pull Requests bitte prüfen:

- [ ] Rechtschreibung
- [ ] Markdown korrekt
- [ ] Dateiname korrekt
- [ ] Quellen ergänzt
- [ ] Fachlich geprüft
- [ ] Lehrplankonform
- [ ] Didaktisch passend

---

# Issues

Bitte Issues verwenden für

- Fehler
- Verbesserungsvorschläge
- neue Kapitel
- neue Materialien
- Fragen
